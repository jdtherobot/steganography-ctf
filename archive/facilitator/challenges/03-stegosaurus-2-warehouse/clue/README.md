# Challenge 3 physical clue — the warehouse note

**FACILITATOR ONLY.** This is the reward players *earn* by resolving the VA to
row 2 / shelf level 1 (bottom) / back bay / sub-section 1 / box 5. Never ship it
with the participant bundle — handing it out skips the entire page-table puzzle.

| File | Role |
|---|---|
| `warehouse_note.svg` | canonical printable asset (regenerated by `../rebuild.sh`) |
| `warehouse_note.png` | raster convenience copy for quick printing (best-effort output of `rebuild.sh`) |

The note's face carries exactly this text — nothing more:

* corners: `Honey` (TL), `Badger` (TR), `Heck` (BL), `Yeah` (BR)
* center: `dCode` followed by four empty squares
* below center: `Line #9`

This text is the **source of truth mirrored by the warehouse game** — if the
note ever changes, the game's reveal must change with it (and vice versa).

For live events: print at **5 in × 3 in** (index card; the SVG is 1000×620, so
landscape A6/4×6 photo paper also works), fold along the dashed creases into a
2×2 square, and place it in the correct box before play starts.
