# Challenge 2 · Steganography lvl 2 — Facilitator Writeup

**FACILITATOR ONLY — contains the flag and every secret. Never hand to players.**

| | |
|---|---|
| Technique | `steghide` payload hidden in a JPEG behind a guessable passphrase |
| Distributable | `stego_badger.jpeg` |
| Passphrase | `password123` (a common `rockyou` entry) |
| Flag | `Flag{DanG 7hat'S @ cUTe HOnEY b@D9eR}` — line 1 of the extracted document |
| Tools | `steghide` + a cracker (`stegcracker`/`stegseek`) + a wordlist |

## My steps (how it was built)

**Create the stego JPEG:**
```
steghide embed -cf inputImage.jpg -ef fileWithFlag -sf outputImage.jpg -p passphrase
```
The embedded file is a **202-line document**:
- **Line 1** — the flag.
- **Line 9** — `UPNAHLNSIBESOLTUEBUPDNEY` (the four-square ciphertext the Warehouse needs).
- **Lines 2–202** — 201 filler 24-character strings (generated by `genstring.py`).

## Player steps (intended solve)

*(The wordlist is **not** shipped in `participant/` — players bring their own; the intended one
is Kali's `rockyou`, which the hint "WE WILL, WE WILL…" points at.)*

1. **Brute force** — the passphrase is a common one:
   ```
   zcat /usr/share/wordlists/rockyou.txt.gz > /tmp/rockyou.txt
   stegcracker outputImage.jpg /tmp/rockyou.txt          # or: stegseek --crack outputImage.jpg /tmp/rockyou.txt
   ```
   → passphrase `password123`.
2. **Extract:**
   ```
   steghide extract -sf outputImage.jpg -p password123 -xf extracted.txt
   head -n1 extracted.txt
   ```
   → `Flag{DanG 7hat'S @ cUTe HOnEY b@D9eR}`

## The cross-challenge tie (do NOT reveal to players)

The extracted document is load-bearing beyond line 1:
- **Line 9** (`UPNAHLNSIBESOLTUEBUPDNEY`) is the **Computer Architecture Warehouse**
  four-square ciphertext.
- The **201 filler strings** (lines 2–202) are the same 24-character records that make
  up **Steganography lvl 3**'s `STEGO_KEY_368.txt`. That is why the Warehouse hint asks
  *"have you beaten lvl 2?"* — a player who kept this document is holding key material for
  two later challenges.

The document is never shipped; players recover it by solving. Keep it whole.
