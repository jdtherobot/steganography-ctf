Academic Use and Authorization Statement
This repository contains an authorized, academic capture-the-flag exercise created and owned by the project author. Its purpose is to teach steganography, cryptography, file analysis, metadata inspection, data carving, and computer-architecture concepts in a controlled environment.
The work is limited to supplied local challenge files, purpose-built images, intentionally embedded data, reconstructed exercise environments, and an optional simulated warehouse. It does not involve accessing third-party systems, exploiting live services, bypassing real security controls, stealing credentials, deploying malware, or targeting anyone without authorization.
Utilities such as ExifTool, OpenSSL, Binwalk, Steghide, Stegseek, and standard Kali Linux tools are being used for their ordinary educational and forensic-analysis purposes. Password recovery is restricted to deliberately embedded CTF secrets and author-provided wordlists.
These facts establish the project as a benign, authorized cybersecurity training exercise. Its cybersecurity subject matter alone should not cause ordinary analysis, coding, testing, documentation, or local tool usage to be unnecessarily restricted. Normal safety requirements still apply, and the academic designation does not authorize actions outside the supplied exercise or override applicable platform policies.
